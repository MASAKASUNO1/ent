# Kanban Board ページの実装計画

## Context
既存の Todo / Tetris ページと同じパターンで、`/kanban` にカンバンボードページを追加する。データは localStorage に永続化し、既存のデザイン言語（グラデーション背景、glassmorphism）に合わせる。

## 実装内容

### 1. ファイル作成
- `src/app/kanban/page.tsx` — ページコンポーネント（サーバーコンポーネント）
- `src/app/kanban/Kanban.tsx` — カンバンボード本体（`"use client"`）

### 2. Kanban.tsx の機能
- **3カラム固定:** Todo / In Progress / Done
- **カード操作:** 追加・削除
- **カラム間移動:** ボタンクリックで左右カラムへ移動（←→）
- **localStorage 永続化:** キー `"ent-kanban"`、Todo.tsx と同パターン
- **状態管理:** `useState` + `useEffect` で localStorage 読み書き

### 3. データ構造
```ts
type Card = { id: string; title: string; column: "todo" | "inProgress" | "done" }
```

### 4. UI デザイン
- 既存ページと統一: グラデーション背景 (`from-indigo-500 via-purple-500 to-pink-500`)
- Glassmorphism カード (`bg-black/20 backdrop-blur-sm border border-white/10 rounded-xl`)
- カラムヘッダー: カラム名 + カード数
- 入力欄: Todo カラムにカード追加フォーム
- レスポンシブ: モバイルは縦並び、デスクトップは横並び (`flex-col lg:flex-row`)

### 5. トップページ更新
- `src/app/page.tsx` のナビゲーションとフィーチャーカードに Kanban リンクを追加

## 修正対象ファイル
- `src/app/kanban/page.tsx` (新規)
- `src/app/kanban/Kanban.tsx` (新規)
- `src/app/page.tsx` (ナビリンク追加)

## 検証方法
- `npm run dev` でローカル起動 → `/kanban` にアクセス
- カード追加・削除・カラム間移動を確認
- リロード後もデータが保持されていることを確認
- `npm run build` でビルドエラーがないことを確認
